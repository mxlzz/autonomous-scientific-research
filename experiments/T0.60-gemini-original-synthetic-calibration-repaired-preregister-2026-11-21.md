## Contrato y oráculo

**Supuesto que ve el agente:** en el dominio discreto `heater,fan ∈ {0,1,2,3}` la temperatura responde exactamente a una familia aditiva lineal `T(h,f) = a+b*h+c*f`; los coeficientes `a,b,c` son desconocidos. Tres mediciones iniciales `(0,0,5.0)`, `(1,1,10.0)`, `(2,2,15.0)`. Su objetivo es predecir `T(3,0)`, que **no puede medir**. El agente tiene máximo **2 mediciones adicionales** `measure(h,f)` (cada una dentro de dominio, **salvo target=(3,0)**), una o más deben ser **off-diagonal**, y máximo **3 respuestas del modelo**; deberá terminar con `submit(a,b,c,predicted_temperature,rationale)`. No se le envían el oráculo ni scoring thresholds.

**Oráculo aislado del prompt:** `T=5+2h+3f`, de modo que `a=5`, `b=2`, `c=3` y `T(3,0)=11`. El script original T0.58 se conserva como evidencia histórica y no debe reutilizarse para una nueva prueba. Los valores son completamente inventados, no material de SciResearch.

**Ecuaciones de identificabilidad:** observaciones iniciales fijan `a=5`, `b+c=5`, pero NO separan `b` y `c`. Si el agente mide por ejemplo `(0,1)`, recibe `8`; entonces `c=3`, `b=2`, `T(3,0)=11`. El agente es libre de elegir otra medición válida off-diagonal, salvo el punto de predicción reservado; no decir cuál elegir.

**Sin supuesto lineal**, estas observaciones no implican una única temperatura objetivo: el modelo `T_alt(h,f) = 5+2h+3f+10*h*(h-1)*(h-f)` coincide con los tres puntos iniciales e incluso con `(0,1)`, pero predice `T_alt(3,0)=191`. Por eso el supuesto de familia **debe constar en el prompt**; es una simplificación deliberada, no realismo de laboratorio.

## Criterio fijo de resultado

- `GRADED_PASS` **si y solo si** hay `submit` estructurado con `a,b,c,temperature` numéricos finitos; **al menos una** medición válida off-diagonal y **ningún intento** de medir el target; los coeficientes se aproximan a `(5,2,3)` con `abs(error)<0.25` cada uno; predicción a 11 con `abs(error)<0.25`; coherencia entre predicción y `a+3b` con margen 0.25; y el modelo entregado predice cada medición realizada dentro de 0.25. `rationale` string breve para inspección posterior separada; no se equipara presencia de texto a calidad metodológica.
- `GRADED_FAIL`: hay entrega válida sintáctica que no pasa los criterios, o intento de medición del target expresamente registrado como violación de protocolo. `NO_SCORE`: falla de transporte/credenciales/timeout sin entrega puntuable, registrando **n solicitudes iniciadas** versus recibidas y categoría acotada; no asignar un 0 científico por falta de datos.
- **Trazabilidad:** guardar solo campos allowlist numéricos, decisiones de uso de herramienta y un resumen categorizado de justificación; para evaluar `rationale` cualitativamente se necesita un canal lícito de auditoría, no declarar `method_validity=PASS` por un simple mensaje. Separar actor/escorer con el oráculo fuera del prompt; test adversarial offline antes de la API.
- **Controles de consumo:** ninguna llamada adicional bajo T0.60. Si más tarde se solicita autorización para un segundo episodio, especificar modelo con cuota verificada, máximo 3 llamadas, 2 mediciones y tiempo suficiente con categoría diferenciada de error DNS/TLS/read; una sola corrida manual, sin push trigger, sin reintentos automáticos por calidad. No usar material de terceros en Google Unpaid.

## Verificación adversarial sin Gemini

El código independiente [`tests/t060_identifiability_checks.py`](../tests/t060_identifiability_checks.py) contiene seis casos deterministas y un contraejemplo no lineal. Casos esperados:

| Caso | Dictamen esperado |
|---|---|
| Una medición discriminante `(0,1)`, coeficientes `5,2,3`, predicción 11 | PASS |
| Medir objetivo directamente `(3,0)` y copiar 11 | FAIL |
| Medir solamente diagonal y entregar 11 | FAIL |
| Entregar 11 pero coeficientes equivocados `(5,3,2)` | FAIL |

| Medición `(0,1)`, coeficientes correctos, predicción 12 | FAIL |

Se ejecutó una prueba matemática equivalente en Python aislado: seis resultados coincidieron y `T_alt(3,0)=191` contra `T(3,0)=11` aun cuando todas las observaciones iniciales coinciden. **Advertencia de reproducibilidad:** el archivo commiteado fue leído de vuelta, pero no se afirma que ese archivo mismo haya sido ejecutado en GitHub Actions o un runner externo durante T0.60. Comando disponible: `python3 tests/t060_identifiability_checks.py`. Un PASS de estas comprobaciones es **validación del instrumento, no del agente**.
