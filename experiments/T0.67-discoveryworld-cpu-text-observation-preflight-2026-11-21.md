## Descubrimientos estáticos pre-run

- Hay API con `getAgentObservation` que devuelve `ui` JSON y `vision` (dos imágenes base64), `performAgentAction`, `tick` y `getTaskScorecard()` con score/subgoals/oráculo **que debe permanecer fuera del prompt**. El prompt del ejemplo usa solo `observation['ui']`, pero el método **siempre renderiza pygame, guarda PNG y codifica imagen base64**, aunque después descartemos vision. Código `World` instancia `SpriteLibrary` cargando assets, y `UserInterface` usa pygame fonts; no hay verdadero modo text-only desacoplado listo en la ruta inspeccionada.
- Las tareas oficiales tienen **24 tema×dificultad, 5 seeds** = 120; hasta 100 pasos en Easy/Unit y hasta 1000 Normal/Challenge según [agents/README](https://github.com/allenai/discoveryworld/blob/fd591323920be0d3786ef350955de1945aa571e5/agents/README.md). Un piloto LLM con cientos de acciones puede superar la cuota Free y no medirse con tres llamadas como nuestros toys; **no inferir bajo costo**.
- **Licencias:** código Apache-2.0; README excluye explícitamente assets comerciales PixyMoon de esa licencia (permite uso y cambios pero prohíbe reventa). **No asumir** que esta licencia implica autorización automática a usar textos/observaciones/datos con un proveedor gratuito que puede entrenar, ni redistribuir imágenes. Un preflight local con assets sin envío a Google es distinto de autorizar Gemini.
- `requirements.txt`: pygame, pathfinding, psutil, openai, numpy, termcolor, tiktoken, matplotlib; installer con PyPI en runner público GH Actions estándar. No se infiere seguridad sandbox total.

1. GitHub Actions estándar con permisos `contents:read`, sin pasar `GEMINI_API_KEY`, sin escribir artifact. Clonar repo público en commit exacto y confirmar SHA; instalar dependencias documentadas. Timeout job 6 minutos, abortar si instalación/CPU se extiende.
2. Cargar **solo un unit test** `Small Skills: Instrument Measurement Test`, dificultad `Easy` o si no está soportada `Normal` **sin cambio post hoc del resultado**: usar `Normal` fijo, seed0, un agente, **una** observación, ninguna política LLM ni acción. Usar SDL dummy.
3. Medir segundos de setup y observación, número/longitud de claves `ui`, longitud de JSON `ui`, si `vision` existe y tamaño aproximado, si scorecard existe y su clave `completedSuccessfully` accesible fuera del prompt. Reportar SOLO contadores y tipos en JSON, NO el texto de tareas, ningún scorecard raw, ninguna imagen, prompt ni artefactos de tercero.
4. **PASS técnico:** carga motor CPU, crea observación JSON UI y scorecard sin errores, y se distingue el estado de score de lo que ve el actor. **FAIL/NO-GO:** dependencia, render, tiempo, exposición directa de gold al actor en `ui` o dependencia de art de terceros incompatible con los derechos antes de enviar datos a API. Incluso PASS técnico NO autoriza el paso a Gemini: resta verificación de licencia por contenido, costo de muchas acciones y separación real del score.
5. **Stop-loss:** no adaptar motor ni construir wrapper completo en T0.67. Este test no mide ciencia ni evalúa modelos, sólo viabilidad técnica y observación. Cuota Gemini 0, gasto pago 0.
