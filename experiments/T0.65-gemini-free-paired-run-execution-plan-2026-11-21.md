# T0.65 — Plan de ejecución congelado para piloto pareado Gemini Free

**Fecha:** 2026-11-21, redactado antes de activar cualquier llamada del estudio pareado. Se aplica [prerregistro T0.64](T0.64-two-original-scientific-cases-paired-preregister-2026-11-21.md), [gate offline PASS](../evidence/T0.64-two-original-science-cases-offline-gate-pass-2026-11-21.md) y autorización [D-0076](../evidence/T0.63-free-gemini-authorization-scope-2026-11-21.md).

- Runner [`scripts/t065_paired_gemini.py`](../scripts/t065_paired_gemini.py) importará leyes/herramientas/score desde `scripts/t064_cases.py`, y la función HTTP autenticada ya verificada de `scripts/t061_gemini_identifiability.py`. **No framework.**
- **Única invocación CI** con gate `python3 -m py_compile`, `python3 scripts/t064_cases.py --self-test`, `python3 scripts/t065_paired_gemini.py --self-test`. Solo si PASS, habilitar el secret existente `GEMINI_API_KEY` y lanzar comparación. No acceso a benchmarks SciResearch.
- Una llamada GET de visibilidad de metadatos por modelo (no consume episodio de generación; NO certifica cuota numérica); si no está visible, registrar `NO_SCORE` y saltar ese modelo sin fallback a paga. Sin habilitar Cloud Billing.
- Orden **congelado**: (A mechanisms, Flash-Lite), (A mechanisms, Flash), (B outlier, Flash), (B outlier, Flash-Lite). Mismas preguntas, herramientas y scoring por tarea. **4 episodios distintos máximo**, ≤3 peticiones chat-completions por episodio, ≤2 mediciones, `temperature=0`, `max_tokens=1536`, timeout por POST 75 segundos, metadata GET 15 segundos. No retry automático por score ni transporte. Si API devuelve 429/503/socket timeout, `NO_SCORE` para episodio, registrar categoría y continuar los otros si no hay error de autorización severo. HTTP401/403 detiene resto. No usar herramientas Google Search/Maps/grounding, ni servicios pagos.
- Trazabilidad en logs de CI: un solo objeto JSON allowlist con etiquetas `science_status` (`GRADED_PASS`, `GRADED_FAIL`, `NO_SCORE`), modelo/caso, medido x, solicitudes iniciadas/respondidas, tokens y segundos declarados, error de oráculo solo numérico, rationale SHA256/len sin texto. No se registra API key, headers ni respuesta literal del actor. `method_review=NOT_REVIEWED`. Sin evaluación cualitativa de texto, no afirmar método completo.
- **Parada:** workflow creado con trigger `push` en su archivo **solo para encolar una corrida**; quitar `push` inmediatamente después de identificar el run y verificar no hay uno adicional. No lanzar otro workflow aunque una celda falle. Si test offline FAIL, no ejecutar episodio (el único run termina falla).
- **Interpretación:** 4 celdas con n1 cada una. Incluso una diferencia de PASS no estima superioridad ni garantiza replicabilidad; resultados útiles para detectar viabilidad/techo y decidir STOP. Calcular número de válidos por modelo sobre 2 casos y `NO_SCORE` aparte; ningún resultado mide continuación temporal H0. Si ambos 2/2 PASS, no gastar más cuota en estos toys; diseñar alternativa científica más exigente o pausar.
- **Presupuesto real:** USD0 de llamadas de pago o infra paga, licencia gratuita reportada por el usuario. Cuota efectiva por modelo desconocida hasta respuesta de proveedor; bajo error 429, parar según contrato. Budget ≤12 peticiones generativas; no usar la autorización amplia como obligación de agotar saldo.
