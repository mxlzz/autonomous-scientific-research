# Registro de benchmarks

Directorio para manifiestos, configuraciones fijas y resultados de evaluación, **no para copiar datasets sin licencia**.

Candidatos iniciales: AstaBench (R06), ResearchGym (R07), ScienceAgentBench (R08), según RESEARCH.md. En T0.3 elegir 6–8 tareas piloto con origen, versión, partición, criterios de éxito, licencia, coste estimado y posible contaminación. No existe aún benchmark ejecutado. Archivo sugerido al iniciar: manifest.json con id, fuente, versión, licencia, evaluador, hash y ruta de salida.
