- **PASS:** variante open-weight disponible, host gratuito, modelo hash pinned, fuente original/sintaxis de acciones congeladas, validación negativa/positiva de frontera anterior a LLM, sin servicios pagados; 1 sola invocación CI.

- **Hipótesis NO comprobadas:** lentitud de prefill 4B con prompt grande, retención de trabajo dentro de `timeout 255`, `think:false` con modelo thinking-only, o contención de CPU por sampler; **ninguna debe declararse causa demostrada sin traza**. La memoria/tiempo no se deducen del tamaño del archivo. No abrir una nueva campaña DiscoveryWorld con simples cambios de prompt.
- **Validez científica:** no hay observación válida de investigación end-to-end; H0 continúa abierto y H1/H2 no habilitados. Este run no es un control comparativo 0.6B/4B, ni prueba incapacidad de 4B.
