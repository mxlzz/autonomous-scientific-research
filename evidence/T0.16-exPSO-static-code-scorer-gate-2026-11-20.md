## Juicio de viabilidad y mínimo camino a ciencia

**Resultado T0.16: PASAN la integridad de archivo, lectura estática de imports/entorno y los tests sintéticos del scorer; NO PASAN los gates para ejecutar la cápsula científicamente sin preparación adicional.** Es incorrecto llamar *experimento de autonomía científica* a esos tests. Original Dockerfile no debería construirse para descubrir viabilidad: fuerza instalaciones pesadas y `RUN /postInstall` no revisado; tampoco usar el harness CORE original `privileged=True`.

**Decisión D-0023 — AJUSTAR PRIORIDAD PARA NO PERPETUAR PREFLIGHTS:** antes de escribir más infraestructura, comparar **una** ruta acotada de ejecución CPU con sandbox disponible y sin privilegios contra el costo/viabilidad real de dependencias. Si no existe ruta de costo0 y seguridad suficiente, **abandonar ExPSO como primera línea base** y seleccionar un benchmark o cápsula de ciencias reales con dependencias CPU ligeras y evaluación externa, sin repetir sondas infinitas sobre ExPSO. En cuanto se obtenga un sandbox garantizado, pasar a **una corrida emparejada inicial** o al menos una reproducción base con score externo y trazas recuperables, no una prueba adicional de metadatos. El posterior agente LLM se introduce sólo cuando la reproducción base sea estable. Ninguna afirmación sobre H1–H6 ni cierre H0.
